# 🎯 Solo Plan — Fullstack Planning Tool

**Solo Plan** is a high-performance, minimalist planning tool designed for individuals who want to manage their time and tasks without the bloat of enterprise software. It features a dedicated Node.js/MongoDB backend to provide persistent, cross-platform task management.

## 🛠️ Engineering Highlights

* **Fullstack Architecture:** Decoupled Frontend (Next.js) and Backend (Node.js/Express) for better scalability and independent deployment.
* **Persistent Storage:** Implemented a robust NoSQL schema using MongoDB and Mongoose to handle complex task structures and user data.
* **Responsive Engineering:** Developed a highly adaptive UI with Tailwind CSS that maintains dashboard functionality across all device screen sizes.

## 🧠 Technical Challenges

* **Fullstack Data Synchronization:** Architected a RESTful API to ensure seamless data persistence and synchronization between desktop and mobile sessions.
* **State Management & Performance:** Leveraged Next.js Server Components and React hooks to manage complex application states without sacrificing Core Web Vitals.
* **Infrastructure Management:** Configured a split-deployment architecture with automated CI/CD pipelines using Railway for the API/DB and Netlify for the Client.

## 💻 Tech Stack

| Layer | Technology |

## 🚀 Getting Started

### Prerequisites
* Node.js (v18.0.0 or higher)
* npm or yarn

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/DimaOliynyk/solo-plan.git
    cd solo-plan
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) to see the result.
