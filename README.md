## 🛠 Features

*   **Minimalist Interface:** Focus on your work, not the tool.
*   **Daily Focus:** Prioritize your most important tasks for the day.
*   **Responsive Design:** Plan from your desktop or on the go via mobile.
*   **Data Privacy:** Designed for personal use with a focus on simple data management.

## 🚀 Getting Started

### Prerequisites

*   Node.js (v18.0.0 or higher)
*   npm or yarn

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/DimaOliynyk/solo-plan.git
    cd solo-plan
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 💻 Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | React / Next.js (App Router) |
| **Backend** | Node.js / Express |
| **Database** | MongoDB (Mongoose) |
| **Styling** | Tailwind CSS |
| **Deployment** | Railway (Backend) & Netlify (Frontend) |
| **Tools** | Git, Postman, npm |

## 🚀 Engineering Overview

### 🧠 Technical Challenges
* **Fullstack Data Synchronization:** Architected a RESTful API with Node.js and MongoDB to ensure real-time data persistence and seamless synchronization between desktop and mobile sessions.
* **State Management & Performance:** Leveraged Next.js Server Components and optimized React hooks to manage complex task states without sacrificing application speed or Core Web Vitals.
* **Responsive Layout Engineering:** Developed a highly adaptive UI using Tailwind CSS that maintains complex dashboard functionality and readability across all device screen sizes.

### 🛠️ Key Engineering Features
* **Full CRUD Operations:** Engineered a robust backend logic for creating, reading, updating, and deleting tasks with complex data schemas in MongoDB.
* **Custom API Integration:** Built a dedicated Express.js server to handle secure user scheduling logic and data validation.
* **Production-Ready Deployment:** Configured a decoupled architecture with automated CI/CD pipelines, utilizing Railway for backend stability and Netlify for frontend delivery.
