**Solo Plan** is a streamlined, focused planning tool designed for individuals who want to manage their time and tasks without the bloat of enterprise project management software.

[**Live Demo**](https://planer.dimaoliinyk.com) | [**Report Bug**](https://github.com/DimaOliynyk/solo-plan/issues)

---

## 🛠 Features

*   **Minimalist Interface:** Focus on your work, not the tool.
*   **Daily Focus:** Prioritize your most important tasks for the day.
*   **Responsive Design:** Plan from your desktop or on the go via mobile.
*   **Data Privacy:** Designed for personal use with a focus on simple data management.

## 🚀 Getting Started

### Prerequisites

*   Node.js (v18.0.0 or higher)
*   npm or yarn

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/DimaOliynyk/solo-plan.git
    cd solo-plan
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
